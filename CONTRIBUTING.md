# Contributing

Спасибо за интерес к проекту. Несколько правил, чтобы правки шли гладко.

## Разработка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/playwright install chromium   # только если трогаете вход /auth/login
cp .env.example .env                     # заполнить своими данными
.venv/bin/python -m pytest -q            # 28 тестов, браузер не поднимается
```

## Правила

- **Никаких секретов в коммитах.** `.env`, `data/`, токены, пароли, реальные номера
  телефонов и домены — только в `.env` (он в `.gitignore`). В примерах — плейсхолдеры.
- Тесты не ходят в сеть и не запускают браузер (`respx`-моки, заглушка входа).
  Новую логику покрывать так же.
- Кодстайл: как в проекте (русскоязычные комментарии/докстроки, FastAPI + httpx).
- Точка правки авторизации — `app/pbx_client.py` (сессия/refresh) и
  `app/browser_login.py` (SSO-вход). Эндпоинты — соответствующий роутер в `app/routers/`.

## Дисклеймер

Проект использует внутреннее API ЛК ВАТС, не имеющее публичной спецификации. РТК может
изменить его в любой момент. Не аффилирован с ПАО «Ростелеком».
